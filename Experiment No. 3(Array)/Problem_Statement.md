# Experiment No. 3 — Matrix Operations Using Multidimensional Arrays in Java

## Problem Statement

Develop a Java program that uses multidimensional arrays to perform various matrix operations. The program should accept input for two matrices from the user and validate their dimensions to ensure compatibility for different operations.

Implement the following operations:

1. Matrix Addition
2. Matrix Multiplication
3. Transpose of a Matrix
4. Row-wise Sum
5. Column-wise Sum

## Aim

To implement various matrix operations using multidimensional arrays in Java and validate matrix dimensions for performing compatible operations.

## Objectives

* Create and use two-dimensional arrays to represent matrices.
* Accept matrix dimensions and elements from the user.
* Validate matrix dimensions before performing operations.
* Perform matrix addition and multiplication.
* Calculate the transpose of a matrix.
* Calculate row-wise and column-wise sums.
* Display the results of each matrix operation.

## Theory

A **multidimensional array** in Java is an array containing other arrays. A two-dimensional array is commonly used to represent a matrix consisting of rows and columns.

### Matrix Operations

**1. Matrix Addition**

Two matrices can be added only when they have the same number of rows and columns. Corresponding elements are added.

**2. Matrix Multiplication**

Matrix multiplication is possible when the number of columns in the first matrix equals the number of rows in the second matrix.

**3. Transpose of a Matrix**

The transpose is obtained by converting the rows of a matrix into columns and its columns into rows.

**4. Row-wise Sum**

The row-wise sum is calculated by adding all elements in each row.

**5. Column-wise Sum**

The column-wise sum is calculated by adding all elements in each column.

## Associated Tasks

1. Accept the dimensions and elements of two matrices from the user.
2. Store the matrices using two-dimensional arrays.
3. Validate matrix dimensions for addition and multiplication.
4. Perform matrix addition when the dimensions are compatible.
5. Perform matrix multiplication when the dimensions are compatible.
6. Calculate and display the transpose of a matrix.
7. Calculate and display the sum of each row and each column.
8. Display the results clearly.

## Concepts Used

* Java Classes and Objects
* Two-Dimensional Arrays
* Nested Loops
* User Input Using `Scanner`
* Conditional Statements
* Matrix Operations
* Input Validation

## Expected Output

The program should accept two matrices from the user and display the results of matrix addition, matrix multiplication, transpose, row-wise sums, and column-wise sums. If the dimensions are incompatible for addition or multiplication, the program should display an appropriate message.

## Conclusion

Thus, various matrix operations are implemented using multidimensional arrays in Java. The program demonstrates matrix addition, multiplication, transpose, row-wise sums, column-wise sums, and dimension validation.
