# Experiment No. 1 — Basic Calculator

## Problem Statement

Implement a robust Java calculator program that dynamically captures user input, evaluates mathematical expressions using conditional logic, and incorporates efficient error handling for invalid or exceptional inputs.

## Aim

To implement simple mathematical functions using basic constructs in Object-Oriented Programming.

## Objectives

- Accept numbers from the user dynamically.
- Validate user input to ensure correct data types and allowed operations.
- Use a `switch` statement to determine the selected operation.
- Implement loops for repeated calculations and menu-driven interaction.
- Display the calculated result clearly.
- Handle invalid and exceptional inputs efficiently.

## Tasks

1. Accept numbers from the user dynamically.
2. Validate the user input.
3. Allow the user to select a mathematical operation.
4. Use a `switch` statement to perform the selected operation.
5. Allow repeated calculations using a loop.
6. Display the result clearly.
7. Handle invalid input and mathematical errors such as division by zero.

## Operations

The calculator should support basic mathematical operations:

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)

## Concepts Used

- Java
- Variables and Data Types
- User Input using `Scanner`
- Conditional Statements
- `switch` Statement
- Loops
- Methods
- Exception Handling
- Input Validation

## Expected Behavior

The program should:

1. Ask the user to enter the required numbers.
2. Display a menu of available operations.
3. Perform the selected operation.
4. Display the calculated result.
5. Allow the user to perform another calculation.
6. Handle invalid choices and invalid input without terminating unexpectedly.
7. Prevent division by zero.

## Conclusion

Thus, a Java-based calculator was implemented successfully using basic programming constructs, conditional statements, loops, user input validation, and error handling.
