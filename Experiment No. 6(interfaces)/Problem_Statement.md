# Experiment No. 6 — Multiple Inheritance Using Interfaces in Java

## Problem Statement

Write a Java program to create two interfaces, `Academic` and `Sports`, each containing methods to store and display their respective details. Implement both interfaces in a class `Student` to demonstrate multiple inheritance and display the combined student information.

## Aim

To develop a Java program demonstrating multiple inheritance using interfaces.

## Objectives

- Create two interfaces, `Academic` and `Sports`.
- Define methods to store and display details in each interface.
- Implement both interfaces in the `Student` class.
- Accept and display combined student information.
- Demonstrate multiple inheritance using interfaces in Java.

## Theory

An **interface** in Java defines a set of methods that a class can implement. Interfaces help achieve abstraction and support multiple inheritance of type.

Java does not support multiple inheritance through classes, but a class can implement multiple interfaces.

In this program:

1. **Academic:** Stores and displays academic details, such as roll number and marks.
2. **Sports:** Stores and displays sports details, such as sport name and score.
3. **Student:** Implements both interfaces and displays the combined information.

## Associated Tasks

1. Create the `Academic` and `Sports` interfaces.
2. Define methods to store and display academic and sports details.
3. Implement both interfaces in the `Student` class.
4. Accept student information from the user.
5. Display the combined academic and sports details.

## Concepts Used

- Classes and Objects
- Interfaces
- Multiple Inheritance
- Method Implementation
- Abstraction
- User Input Using `Scanner`

## Exemplars and Utility

### Exemplars

1. Student Performance Management System
2. College Activity Record System
3. Sports and Academic Tracking Application
4. School Information System

### Utility

This program helps in understanding interfaces, multiple inheritance, and the implementation of shared functionalities. These concepts are useful in student management systems and applications that combine academic and extracurricular records.

## Expected Output

The program should accept academic and sports details from the user and display the combined information using the `Student` class.

## Conclusion

Thus, multiple inheritance is demonstrated successfully in Java by implementing the `Academic` and `Sports` interfaces in the `Student` class. The program combines and displays academic and sports information for a student.
