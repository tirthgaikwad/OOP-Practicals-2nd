# Experiment No. 9 — Employee Directory Using Collections Framework in Java

## Problem Statement
Develop a simple Java application to manage an Employee Directory using the Java Collections Framework. Store employee details using collection classes such as ArrayList, HashSet, and HashMap. Use an Iterator to display employee records and demonstrate the basic collection hierarchy.

## Aim
To understand and implement Java Collections Framework using ArrayList, HashSet, HashMap, and Iterator.

## Objectives
1. Understand the basic hierarchy of the Java Collections Framework.
2. Store employee records using ArrayList.
3. Store unique employee records using HashSet.
4. Store employee details using HashMap with Employee ID as the key.
5. Display records using Iterator.

## Theory

The **Collections Framework** in Java is used to store and manage groups of objects.

### Collection Classes

| Collection | Description |
|---|---|
| ArrayList | Stores elements in order and allows duplicates. |
| HashSet | Stores unique elements and does not maintain insertion order. |
| HashMap | Stores data in key-value pairs. |
| Iterator | Used to access elements one by one. |

### Basic Collection Hierarchy

- Iterable is the parent interface of Collection.
- Collection is the main interface.
- List, Set, and Queue are child interfaces of Collection.
- ArrayList implements List.
- HashSet implements Set.
- Map is a separate interface and is not a child of Collection.
- HashMap implements Map.

## Tasks
1. Create an Employee class with ID, name, and salary.
2. Create an ArrayList to store employee records.
3. Create a HashSet to store unique employee records.
4. Create a HashMap to store employees using Employee ID as the key.
5. Use Iterator to display employee records.
6. Display employee details from all three collections.

The program should display employee records stored in ArrayList, HashSet, and HashMap.

This practical demonstrates how to manage employee records using ArrayList, HashSet, and HashMap. It also explains the basic collection hierarchy and the use of Iterator in Java.
