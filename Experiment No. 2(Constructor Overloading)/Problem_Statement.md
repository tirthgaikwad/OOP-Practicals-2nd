# Experiment No. 2 — Constructor Overloading in Java

## Problem Statement

Write a Java program to create a class `Employee` with data members `id`, `name`, and `salary`. Use **constructor overloading** to initialize employee objects in different ways using a default constructor, a constructor with name only, a constructor with name and salary, and a constructor with all details.

Display the employee details and calculate the annual salary of each employee.

## Aim

To implement constructor overloading in Java by creating an Employee class with different ways of object initialization and calculating annual salary.

## Objectives

* Create an `Employee` class with data members `id`, `name`, and `salary`.
* Implement multiple constructors using constructor overloading.
* Initialize employee objects with different parameter combinations.
* Display employee details.
* Calculate and display the annual salary of each employee.

## Theory

**Constructor overloading** in Java means defining multiple constructors in the same class with different parameter lists.

It allows objects to be initialized in different ways depending on the information provided during object creation.

In this program, four constructors are used:

1. **Default Constructor:** Initializes an employee with default values.
2. **Constructor with Name Only:** Initializes an employee using the name.
3. **Constructor with Name and Salary:** Initializes an employee using the name and salary.
4. **Constructor with All Details:** Initializes an employee using the ID, name, and salary.

The annual salary is calculated by multiplying the monthly salary by 12.

**Formula:**

Annual Salary = Monthly Salary × 12
